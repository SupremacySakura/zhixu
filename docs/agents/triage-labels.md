# 分诊标签

这些技能使用五种规范的分诊角色。本文件将这些角色映射到此仓库议题跟踪器中的实际标签字符串（沿用默认命名，无重命名）。

| mattpocock/skills 中的标签 | 我们跟踪器中的标签 | 含义                                   |
| -------------------------- | ------------------ | -------------------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估此议题                   |
| `needs-info`               | `needs-info`       | 等待报告者提供更多信息                 |
| `ready-for-agent`          | `ready-for-agent`  | 规格完整，可交给无需人工值守的代理处理 |
| `ready-for-human`          | `ready-for-human`  | 需要由人类实现                         |
| `wontfix`                  | `wontfix`          | 不会采取行动                           |

当技能提到某个角色（例如“添加 AFK-ready 分诊标签”）时，使用此表中对应的标签字符串。
