# ADR-0005：演化判定只按候选门槛筛选，结论类型交给模型

- **状态**：已采纳
- **日期**：2026-11-15
- **相关**：第六章实验 4.5/4.6、[术语表](../../GLOSSARY.md)；取代 `docs/tasks/evolution-semantic-dedup-20261112.md` 中「Go 按向量相似度分派允许的结论类型」的分派规则

## 背景

演化检查原先按相似度分派结论类型：≥0.90 只允许重复、0.75–0.90 只允许冲突、≥0.80 允许过时，且 0.80 同时充当候选准入门槛。这套规则的设计意图是「越像越可能是重复」，重复与冲突互斥。

第六章实验证明这个前提在中低相似度区间不成立：

- 端到端准确率只有 0.409（9/22）。16 组正样本里 13 组没有产生提醒，**全部**卡在 0.80 的候选门槛之外，模型根本没被调用。
- 以 0.01 为步长穷举全部阈值组合，最优准确率也只有 0.636，而逐对判定的上限是 1.000。剩下的 0.364 不是调参问题。
- 原因是分布重叠：重复样本的相似度区间 `[0.652, 0.771]` 被冲突区间 `[0.571, 0.890]` 完整包含。任何能覆盖全部重复样本的阈值都会把高分冲突样本划进重复带宽，反之则重复样本全部掉出去。

另一个触发因素来自产品需求：嵌入模型可替换，而相似度的绝对水平随模型而变。三个互相耦合的硬编码阈值意味着用户每换一次模型就要重调三个数，实际上没人调得动。

## 决策

1. **新增 `EvolveCandidateMinScore`（演化候选门槛）**，用户级可配，默认 0.65。它只回答「这条候选值不值得送模型」，不再决定结论类型。
2. **删除按相似度切分重复与冲突的带宽**。`evolutionAllowedTypes` 不再接收分数，只保留来源分派：`updates` 关系指向的强候选只允许 `outdated`，向量近邻不再预先限制类型。
3. **删除 `EvolveDuplicateMinScore`、`EvolveConflictMinScore`、`EvolveOutdatedMinScore` 三个常量**。候选门槛与过时阈值解耦后，`score >= 0.80` 对进入判定的候选恒为真，保留它就是死代码。
4. **保留同一对只留一条的收敛逻辑**，优先级仍为重复 → 冲突 → 过时。类型由模型给出后，同一对仍可能产出多条互相矛盾的结论，收敛规则是唯一防线。
5. **换嵌入模型时不重置阈值**，只把设置标记为「待校准」并在界面提示。静默重置会把用户调好的值改回去；什么都不做则把适配责任推给用户却不给信号。

## 理由

4.6 的模拟给出方向：门槛取 0.61–0.65 时 13/16 正样本进入判定、6/6 对照被挡住，估计准确率 0.864。这个上界成立的前提正是「相似度只做筛选、类型交给模型」——它把二维的阈值矛盾降成一维的门槛选择。

保留下限而不是取消门槛，是因为对照样本最高相似度 0.601：再往下放，无关知识会被送进模型，靠模型自己拒掉既浪费调用也不可靠。

默认值取 0.65 而非维持 0.80，是因为 0.80 在本实验里对应 0.409 的准确率。若默认值不变，「可配置」就只是一个开关，用户装上系统看到的仍是「演化检查几乎没反应」。

## 后果

- **提示词成为唯一的类型判据**。`/evolve` 的指令必须补上「重复 = 信息重合可归档其一；冲突 = 同一事实互斥结论」的区分标准，否则问题会从漏报滑向误分类。这是本次改造最大的新风险点。
- **实验数字必须带阈值前提**。0.65 是针对 `embeddinggemma` 768 维、12 篇语料测出来的；换成 1024 维模型后相似度分布整体平移，同一数字不再可比。报告里不能出现不带阈值的准确率。
- **旧数据不可直接对比**。改造前跑出的 collect 明细按旧分派规则判定，与新规则下的数字混在一张表里会误导读者。
- **配置面扩大**。用户多了一个可调数字，设置页需要说明它影响什么，并且这个值要和「向量是否需要重建」的提示绑在一起——`needs_reindex` 为真时向量集合还是旧的，此时无论门槛取多少，相似度都是混算的。

## 备选方案

- **保留三档阈值全部可配**：改动最小，但可配只是把「三个数调不好」的权力交给用户；4.5 已证明这三者在中低相似度区间互相挤压，配得越多越容易配错。
- **只留一个门槛，过时也完全交给模型判**：概念上更干净，但过时判定依赖 `updates` 关系这条用户确认过的强信号，取消来源分派会让强候选与弱候选走同一条路，风险大于收益。
- **换 1024 维以上嵌入模型让区间分开**：若区间能分开，本次改造可以简化。但这需要重嵌入全部 310 个分块并重跑两组实验，且不保证一定分得开，作为并行方向保留而非前置条件。
