# Markdown 知识前端

按 `design/MarkdownKnowledge.html` 的浅色品牌绿风格接入真实后端。删除语义与接口见 [Markdown 知识后端](./markdown-knowledge-backend.md)。

## 功能

- 文件列表、网格与更多菜单提供单文件加入入口，仅 `.md/.markdown` 支持，未加入且大于 20 MiB 的文件禁用提交。
- 标题默认去扩展名，提交前按 Unicode 字符校验 1–200 字符。
- 弹窗使用原生 dialog 处理焦点限制，motion-v 负责面板入场；移动端底部布局。提交中不允许关闭，关闭后恢复触发前焦点。
- 排队/处理面板为非阻塞浮层。关闭只隐藏面板，不取消后台任务；页面卸载取消前端轮询，不取消持久化任务。
- 文件状态每三秒轮询活动任务；新提交后更新文件行状态。未加入返回 404 是预期结果，网络异常则显示状态查询失败，不误显示加入入口。
- `/home/knowledge` 支持标题搜索、状态筛选、分页、空态、错误重载和失败原因查看/重试。
- `/home/knowledge/:id` 展示安全渲染正文和来源快照；活动任务自动查询直到完成。
- 文件删除确认框提供“同时删除关联知识条目”，每次打开默认不勾选；文件夹提示包含子目录。当前对所有文件展示该选项，不预先检查关联状态。
- 知识列表提供独立删除确认，明确保留原文件；失败显示原因，成功刷新列表，删除末页后自动收缩页码。
- 状态筛选复用从文件工具栏抽取的共享 `FilterMenu`，不使用原生 select；支持点击外部关闭、方向键、Home/End、Escape 和焦点恢复。
- 仪表盘操作日志覆盖知识域：加入（高亮来源目录）、移出知识库、重试导入；文件/文件夹删除级联知识时副标题显示「已删除，含 N 条知识」。文案映射在 `utils/operationLog.ts` 的 `describeOperationLog`。

## 安全与边界

- 不执行原始 HTML，不加载 Markdown 图片，不提供危险协议或相对资源链接。代码和正文仍安全显示。
- 不实现摘要、标签、AI、编辑或批量加入；知识删除目前从列表发起。
- 后端仅有整体状态，面板不展示虚构步骤进度或百分比。
- 原文件目录链接依赖加入时快照；文件移动或删除后可能无法找到，不标为精确定位。
- 当前按可见文件逐个查询知识状态，后端批量联查是后续优化项。
- 原设计稿表述“原文件更新后重试”不适用于当前上传模块：空文件重试仍为空，需重新上传有效文件。

## 验证

前端全量 142 项测试、Lint 和生产构建通过。新增测试覆盖安全渲染、文件类型、请求竞态、轮询清理、标题校验、列表空态/失败信息、弹窗提交/焦点恢复、删除选项重置、删除请求和菜单键盘交互。

浏览器通过独立 5174 端口验证未登录路由跳转；浏览器无登录态，没有执行真实账号下的上传及知识入库联调。没有停止既有 5173 开发进程。

本轮删除功能未执行真实账号的 HTTP/数据库联调。Go 后端没有热更新，需要重启根目录 `pnpm dev` 才能加载新接口。

pnpm 安装新增 `markdown-it` 与 `@types/markdown-it`，工作区锁文件同时补齐现有 `zhixu-ai` 的依赖。源码未修改 AI 子项目。
