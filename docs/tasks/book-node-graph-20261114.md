# 知识图谱节点改为书本节点

## 背景

知识图谱原先用方块表示知识，节点形态与「一条知识是一本书」的产品隐喻脱节。本次只改图谱节点及其图例：保留现有深色画布、力导向布局、关系边、筛选、抽屉和后端接口，不把知识库列表页的「硬卡 + 右侧纸条」语言复制到画布。

## 结果

- **书本形态**：节点改为合上的书，正面封面 + 左侧书脊 + 右侧页口，平面无透视、直角；3:4 纵向，高度 `24 + 3 × min(度数, 12)`（24–60px），宽度取高度 0.75 并取整。
- **材质**：纸白封面、图书馆蓝书脊、墨色外框；不按来源给封面上色，来源编码只落在书脊装订上。
- **来源编码**：外框恒为实线；整条实心蓝 = 手动/网页，蓝脊 + 纸白短缝线 = 文档导入，蓝脊 + 纸白点线 = 表格导入。tooltip 同时显示「来源：PDF」等确切类型。
- **中心与选中**：中心节点封面右上角加蓝色书签带，不改变尺寸；选中节点画 3px 蓝色环并提亮邻接边，不做位移、缩放或弹簧。
- **封面细节**：高度 ≥30px 时加两条短墨线，<30px 隐藏；≥42px 时页口由单线变为双线。
- **图例**：新增「书本 = 知识」与三本迷你书，解释三种书脊装订；与节点 SVG 使用同一套来源分组。
- **实现**：`graphNodeSvg()` 生成 75×100 viewBox 的多色 SVG，`graphNodeSymbol()` 输出带 `image://` 前缀的 data URI；选中/中心变化只 `setOption` 更新节点 data 与边样式，不重建 series。
- **文档**：根 `GLOSSARY.md` 增加「书本节点」术语，`DESIGN.md` 增加画布原型规则，`docs/frontend-structure.md` 同步图谱页口径并修正旧的「节点颜色按来源类型」描述。

## 决策与理由

- **只在图谱页使用书本节点**：书本是画布的知识隐喻；列表页已有自己的卡片语言，混用会让两个页面的信息层级失真。
- **书名不印在封面上**：节点是图标级，24px 最小尺寸无法承载可读标题；标签继续放在节点右侧并截断。
- **来源归并成三组装订**：八种 `source_type` 按解析形态归并，避免在节点上新增一套难记的八色/八线型编码；外框仍承担轮廓，不承载来源语义。
- **书签与选中环分开**：书签表示「局部图谱起点」，选中环表示「当前打开抽屉的节点」；两者可同时出现，不互相替代。
- **选中不重建图表**：`setOption(option, true)` 会丢力导向位置与 roam 状态；改为局部更新节点 data 与边样式，保持 series 结构不变。
- **邻接边提亮写进 link opacity**：抽屉打开后鼠标会离开画布，依赖 hover emphasis 的高亮会消失；选中时把邻接边 opacity 提到 1，移入抽屉后仍能保持。

## 教训

- **ECharts image symbol 必须带 `image://` 前缀**：只给 `data:image/svg+xml,...` 会被当作未知符号并回退成默认方块。首次接入时真实页面因此短暂退回蓝方块，单测补了前缀断言。
- **ZRImage 不认 `select.itemStyle` 的描边**：选中环画进 SVG 变体，不依赖 ECharts 的 select 状态。
- **多色图形不要用单个 `path://`**：ECharts path symbol 只有一套填充/描边，封面、书脊、缝线三种颜色必须走 SVG 或等价图像方案。
- **线宽要按屏幕像素反算回 viewBox**：节点从 24px 到 60px 变化时，直接用固定 viewBox 线宽会让小书线条过粗；用 `unit` 换算后外框恒为 2px、内部线恒为 1px。
- **来源编码迁移要同步文档与测试**：旧实现把来源放在外框线型上，本次迁到书脊；`graphNodeBinding()`、图例与 `docs/frontend-structure.md` 必须一起改，否则读者会按旧口径理解新节点。
- **ECharts 默认 hover 会放大 symbol**：`emphasis.scale` 默认是 `true`，即使只写 `lineStyle` 也会继承 1.1 倍缩放；要满足“不做缩放”，必须显式写 `scale: false`。

## 残余风险

- 真实库暂时只有手动来源，文档/表格装订未在真实业务数据上目测，仅由单测和预览验证。
- 375 视口下画布本身横向裁切是既有行为；书本可见，但部分节点标签落在画布外。
- 24px 最小书本的书脊细节很小，主要靠轮廓与书脊色块识别。
- 力导向在首次收敛阶段仍可能有轻微移动；选中切换已确认不会重建 series，但没有把「完全静止后的像素级零位移」作为硬断言。
- 图谱调色板仍在挂载时解析一次 CSS 令牌，主题切换后不自动重取，属既有行为，本次未扩展。
