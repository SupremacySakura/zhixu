# 旧设计样张退役与对话交互约束留存

## 背景

仓库根 `design/` 是 2026-09 浅色 Apple 风格的 40 个静态设计样张（HTML/CSS/JS 与一份对话笔记），约 868KB。ADR-0003 在视觉世界替换时把它们保留为「交互结构历史对照」，但当前前端已完成替换，样张不再参与构建、测试或运行时，根目录位置却仍像一个活跃设计入口。

`docs/design/` 是另外三份毕设源头文档，不在本次退役范围。

## 结果

- 删除根 `design/` 的 40 个文件，不新增 `archive/` 副本；完整内容保留在 Git 历史中，旧样张最后一次修改为 `1de029d`，退役前父提交为 `49da639`。
- 将 `design/Chat-notes.md` 中仍有价值的普通对话约束保留在本日志的「保留的交互约束」一节。
- 更新 `README.md` 的项目结构、`docs/markdown-knowledge-frontend.md` 的首段与 `docs/README.md` 的 ADR 索引。
- 新增 [ADR-0004](../adr/0004-retire-legacy-design-samples.md)，并在 ADR-0003 与 `docs/tasks/frontend-visual-world-replacement-20261112.md` 补后续指向。
- `docs/design/` 三份源头文档未改动。

## 决策与理由

- **删除而不是搬到 `archive/`**：Git 历史已经保存完整内容，再复制一份 868KB 旧样张只会增加第二个入口和新的失效引用。
- **保留文字约束而不是保留视觉样张**：普通对话的范围、输入行为、失败语义和实现边界仍可复用；旧 Apple 视觉令牌、圆角和阴影已经作废。
- **新增 ADR 而不是改写 ADR-0003**：ADR-0003 记录的是当时的替换决策；本次是后续退役，单独记录更清楚，也保留决策链。
- **只清根 `design/`**：`docs/design/` 是毕设源头文档，继续作为历史交付材料保留。

## 保留的交互约束

以下内容提取自 `design/Chat-notes.md`，作为普通对话第一版的历史交互基线；若与当前实现冲突，以代码和 `DESIGN.md` v2 为准。

### 范围

- 纯文本多轮对话，使用当前用户配置的对话模型；不调用工具，不连接向量库，不检索文件或知识库。
- 默认选取用户默认对话模型；自定义菜单可选择其他可用模型，仅影响本次会话，不修改全局默认。
- 首版建议单个临时会话，刷新或新建后消息不保留；会话列表、持久化历史、附件、系统提示词编辑、高级参数和工具管理暂不加入。
- 对话发送当前会话已完成的文字上下文；界面显示实际选择的供应商与模型，不根据模型自我介绍判断接入是否正确。

### 交互

- 输入区固定在底部，消息区独立滚动；靠近底部时跟随流式回复，用户向上阅读时不强制拉回。
- Enter 发送，Shift + Enter 换行；中文输入法组合阶段不发送。空白消息不可提交；单条 8000 字符为设计上限，服务端总量上限在实现时统一。
- 生成中禁止重复发送与切换模型，显示停止按钮；取消后保留已收到内容，并明确标记部分回复。
- 有消息或草稿时新建需确认；切换模型也确认清空，避免不同模型混用上下文。
- 首次使用展示三个文字提示，仅填入输入框，不自动调用。
- 未配置模型或凭据时禁用发送，提供模型设置链接；普通对话不要求配置 Embedding。
- 调用失败保留用户消息。认证失败、响应超时、流式中断提供可读提示和手动重试；不自动重发，提醒可能产生费用。
- 重试替换对应失败回复，不重复添加用户消息；重试历史消息时删除该回复之后的消息再生成。
- 回复可复制，剪贴板失败给出手动复制提示；原型使用 `textContent`，不渲染用户 HTML。业务版若加入 Markdown，沿用仓库安全渲染规则。

### 实现边界

- Go 从登录用户配置解析模型与凭据，凭据不返回浏览器。
- 接入 Mastra 时不注册工具、不启用检索与持久化记忆；多轮上下文由临时会话明确传递。
- 调用前须实现端点允许名单与 SSRF 防护；停止操作应尽力取消上游请求，不能保证供应商停止计费。
- 流式只播放公开回复，不展示私有思维链。

## 教训

- **视觉样张和交互说明是两种资产**：旧 HTML 可以退役，但其中的输入行为、失败语义和边界约束仍值得提炼；删除前先分离这两层。
- **根目录的「历史文件」仍会被当成活跃入口**：只在正文里加「过时」警告不够，无法消除目录层级的暗示；要么删除，要么真正移出主工作区。
- **ADR 的后续变化要单独记录**：ADR-0003 保留旧样张是当时决策，本次退役是后续决策；新增 ADR-0004 比改写历史更可追溯。
- **清理前先确认同名目录不是同一对象**：根 `design/` 是静态样张，`docs/design/` 是毕设源头文档，二者不能一起删。
